# PHP + Nginx Single Container Setup

This Docker setup creates a single container running both Nginx and PHP-FPM, with your web files mounted from the host system.

## 📁 Directory Structure

```
your-project/
├── Dockerfile
├── docker-compose.yml
└── logs/                    # Created automatically
    ├── nginx/
    ├── php/
    └── supervisor/
```

Host directory structure:
```
/data/wwwapp/var/www/htdocs/    # Your PHP application files
```

## 🚀 Quick Start

### 1. Create the project directory
```bash
mkdir php-nginx-app
cd php-nginx-app
```

### 2. Create the Dockerfile
Copy the Dockerfile content from the artifact above.

### 3. Create the docker-compose.yml
Copy the docker-compose.yml content from the artifact above.

### 4. Create the host directory
```bash
sudo mkdir -p /data/wwwapp/var/www/htdocs
sudo chown $USER:$USER /data/wwwapp/var/www/htdocs
```

### 5. Create a test PHP file
```bash
echo '<?php phpinfo(); ?>' > /data/wwwapp/var/www/htdocs/index.php
```

### 6. Build and run the container
```bash
# Build the image
docker-compose build

# Start the container
docker-compose up -d

# Check status
docker-compose ps
```

### 7. Test the application
Open your browser and go to: `http://localhost:8001`

You should see the PHP info page.

## 🔧 Configuration

### Environment Variables

You can customize PHP settings using environment variables in docker-compose.yml:

```yaml
environment:
  - PHP_MEMORY_LIMIT=512M
  - PHP_MAX_EXECUTION_TIME=600
  - PHP_UPLOAD_MAX_FILESIZE=100M
  - NGINX_WORKER_PROCESSES=4
```

### Volume Mounts

The main volume mount:
- **Host**: `/data/wwwapp/var/www/htdocs`
- **Container**: `/var/www/htdocs`

Optional volume mounts for customization:
```yaml
volumes:
  # Custom Nginx config
  - ./custom-nginx.conf:/etc/nginx/conf.d/default.conf
  # Custom PHP config
  - ./custom-php.ini:/usr/local/etc/php/conf.d/custom.ini
  # Logs
  - ./logs/nginx:/var/log/nginx
  - ./logs/php:/var/log/php
```

## 🛠 Management Commands

### Start/Stop/Restart
```bash
# Start
docker-compose up -d

# Stop
docker-compose down

# Restart
docker-compose restart

# Rebuild and restart
docker-compose up -d --build
```

### View Logs
```bash
# All logs
docker-compose logs -f

# Nginx logs
docker-compose exec php-app tail -f /var/log/nginx/access.log

# PHP-FPM logs
docker-compose exec php-app tail -f /var/log/php/error.log

# Supervisor logs
docker-compose exec php-app tail -f /var/log/supervisor/supervisord.log
```

### Container Management
```bash
# Enter container shell
docker-compose exec php-app sh

# Check running processes
docker-compose exec php-app ps aux

# Check service status
docker-compose exec php-app supervisorctl status

# Restart services inside container
docker-compose exec php-app supervisorctl restart nginx
docker-compose exec php-app supervisorctl restart php-fpm
```

## 🚨 Troubleshooting

### Common Issues

1. **Permission Denied**:
   ```bash
   # Fix file permissions
   sudo chown -R $USER:$USER /data/wwwapp/var/www/htdocs
   chmod -R 755 /data/wwwapp/var/www/htdocs
   ```

2. **Port Already in Use**:
   ```bash
   # Change ports in docker-compose.yml
   ports:
     - "8080:80"  # Use port 8080 instead of 8001
   ```

3. **PHP Files Not Executing**:
   ```bash
   # Check PHP-FPM status
   docker-compose exec php-app supervisorctl status php-fpm
   
   # Restart PHP-FPM
   docker-compose exec php-app supervisorctl restart php-fpm
   ```

4. **Nginx Not Starting**:
   ```bash
   # Check Nginx configuration
   docker-compose exec php-app nginx -t
   
   # Check Nginx logs
   docker-compose logs php-app
   ```

### Debug Mode

To enable debug mode, add to docker-compose.yml:
```yaml
environment:
  - PHP_DISPLAY_ERRORS=On
  - PHP_LOG_ERRORS=On
```

## 🔄 Updates and Maintenance

### Update Container
```bash
# Rebuild with latest changes
docker-compose build --no-cache
docker-compose up -d
```

### Backup Application
```bash
# Backup application files
tar -czf backup-$(date +%Y%m%d).tar.gz /data/wwwapp/var/www/htdocs
```

### Clean Up
```bash
# Remove unused images
docker image prune

# Remove unused volumes
docker volume prune

# Complete cleanup
docker-compose down
docker system prune -a
```

## 🌐 URL Structure

Once running, your application will be available at:
- **Main Site**: `http://localhost:8001/`
- **Health Check**: `http://localhost:8001/health`

All PHP files in `/data/wwwapp/var/www/htdocs/` will be served by Nginx and processed by PHP-FPM.
